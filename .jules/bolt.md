## 2026-09-21 - Threshold optimization for range product tree multiplication
**Learning:** In pure Python divide-and-conquer binary product trees (`_product_tree`), breaking down sub-ranges all the way to single/double element leaves creates significant call stack and recursive function frame overhead. Raising the base case threshold to `end - start <= 16` and evaluating small leaf ranges with a simple iterative loop eliminates millions of redundant recursive calls for large $n$ while maintaining balanced bit-length sub-products for CPython's Karatsuba big-integer multiplication.
**Action:** When implementing recursive divide-and-conquer algorithms in Python, always introduce a small sequential base-case threshold (e.g. 16 elements) to avoid recursion overhead on small leaf nodes.

## 2025-05-20 - Newton-Raphson Floating Point Convergence Thresholds
**Learning:** In floating-point Newton-Raphson convergence loops initialized with a double-precision initial guess (e.g. `y = x ** (1.0 / n)`), setting relative convergence thresholds to `1e-16` can be tighter than IEEE 754 machine epsilon for non-exact roots. This causes adjacent float values to oscillate (e.g. diff ~7e-15 > 1e-16) and exhausts max loop iterations (100 iterations) every time. Relaxing relative tolerance threshold to `1e-15` stops iteration as soon as maximum double-precision representation accuracy (~15-17 digits) is reached, yielding ~6x speedup.
**Action:** When implementing or optimizing Newton-Raphson loops for 64-bit IEEE 754 floats in Python, use relative tolerance threshold `abs(next_y - y) <= abs(y) * 1e-15` rather than `1e-16` or `next_y == y`.

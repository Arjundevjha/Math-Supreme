## 2025-05-18 - Decimal Precision Input Validation for Numerical Algorithms
**Vulnerability:** Functions configuring `decimal.getcontext().prec` with user-supplied integer or float precision values without upper/lower bound checks or strict type checks allow Denial of Service (DoS) attacks via memory exhaustion and excessive CPU consumption.
**Learning:** Python's `Decimal` module allows setting arbitrary precision levels in thread context. Unbounded inputs (e.g. `precision=10**9` or `precision=-1`) cause process-level high memory allocations or `InvalidOperation` exceptions. Additionally, Python `bool` inherits from `int` (`isinstance(True, int) == True`), allowing boolean values to bypass naive `isinstance(val, int)` checks unless explicitly checked with `isinstance(val, bool)`.
**Prevention:** Always validate numeric precision parameters with bounds checks (e.g. `1 <= precision <= 10000`) and explicitly exclude boolean values (`not isinstance(precision, bool)`) before assigning to `getcontext().prec`.
